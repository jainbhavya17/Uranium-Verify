# Working architecture

The latest user request authorizes the FastAPI backend. It supersedes the previous browser-only architecture in this nested prototype. Do not modify the parent Lovable MVP or the separate Uranium source project.

- Preserve the approved navy/coral visual system, Instrument Serif headings, DM Sans text and shared portal shell.
- Business records and authority come from `services/api/uranium`; React queries use `src/features/api.ts`. Never trust localStorage roles or a browser-generated approval result.
- All screens use `InnerPage`/`PublicShell`. Build record links with `src/components/link.tsx` or the tested source-route adapter.
- Keep external issuer demonstrations labelled at the result. Do not repeat mock banners on ordinary fields. Never convert an unknown or unsupported result into a pass.
- The legacy browser-only implementation and tests are retained in `legacy/frontend`. Do not silently import them into authoritative institutional records.
- No force push, rebase, amend or squash of published Lovable history. No deployment without explicit authorization.
