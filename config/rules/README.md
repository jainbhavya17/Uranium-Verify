# Regulatory rule fixtures

`phase2-demo.json` is a version-controlled SRS v1.1 transcription for the isolated synthetic workflow. It is not an officially approved regulatory pack. The additive seed creates immutable year-specific database rule packs and catalogue entries. Runtime evaluation reads those persisted versions. Source URLs, clauses, printed/PDF pages, applicability and due stages remain explicit.

Live use requires current official-source verification, source checksums, domain-owner approval and reviewed programme/stage/exception applicability. RAG and model-generated rules are not enabled.
